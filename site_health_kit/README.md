# ערכת "בריאות האתר"

כל מה שצריך כדי לבנות את מסך "בריאות האתר" לאתר אחר, בעזרת קודקס.

## מה נותנים לקודקס

את הקובץ **`SITE_HEALTH_KIT.md`**. זה קובץ אחד שמכיל הכול, ופקודה אחת בראשו פותחת אותו לתיקייה.
בראש הקובץ כתוב גם, בעברית, מה בעל האתר יצטרך לעשות בדרך, וההודעה ששולחים לקודקס.

## מה יש כאן

| | |
|---|---|
| `SITE_HEALTH_KIT.md` | הקובץ למסירה. נבנה אוטומטית. לא עורכים אותו ביד |
| `kit/` | המקור שממנו הקובץ נבנה |
| `build_kit.py` | בונה את הקובץ מתוך `kit/` ובודק אותו. שם גם כתובה גרסת הערכה (`KIT_VERSION`) |

בתוך `kit/`:

| | |
|---|---|
| `START-HERE.md` | הקובץ שקודקס קורא ראשון: כללי העבודה, השאלות לבעל האתר, מבנה התיקיות, סדר הבנייה |
| `OWNER-STEPS.md` | כל מה שרק בעל האתר יכול לעשות: חשבונות, מפתח של גוגל, סיסמאות, ההודעות לטלפון, התוסף באתר. לכל צעד יש הודעה מוכנה בעברית, והדרך שבה קודקס מוודא שהצעד הצליח בלי לראות שום סיסמה |
| `spec/` | ההוראות המלאות: מה מודדים, מבנה הנתונים, המסך, המדידות, ההרשאות, הבדיקות |
| `site_health.html` | המסך עצמו. העתק של המסך בינשוף, בלי שום דבר של דיוואני |
| `mock_server.py` | שרת עם נתוני דמה, כדי לראות את המסך עובד |
| `check_screen.js` | בדיקת קבלה של המסך בדפדפן |
| `tools/check_template.py` | בודק שהמסך שנבנה הוא העתק של התבנית ולא כתיבה מחדש |
| `tools/check_access.py` | בודק מבחוץ, מול שרת שרץ, שכל אחד רואה רק את מה שמותר לו |
| `reference/` | דוגמה עובדת ובדוקה לכל מה שמאחורי המסך: מסד נתונים, שרת, מדידות, התראות, השומר שמתריע כשהמדידה נעצרת, והתוסף לאתר. `reference/README.md` מסביר אותה |
| `AGENTS-snippet.md`, `SKILL.md` | שני קטעים קצרים שמזכירים לקודקס את הכללים בכל פעם שהוא חוזר לפרויקט |
| `MANIFEST.json` | רשימת הקבצים, עם גרסת הערכה. נבנה אוטומטית |

## אחרי שינוי ב-`kit/`

```bash
python3 build_kit.py --check
```

הפקודה בונה את הקובץ מחדש ובודקת אותו: שכל קובץ יוצא ממנו בדיוק כמו שנכנס, ושעותק פגום, חתוך
או בשם אחר נדחה בשורה אחת ברורה ולא משאיר אחריו תיקייה חצי מלאה. אם השינוי יוצא למישהו,
מעלים את `KIT_VERSION` ב-`build_kit.py` ואת אותו מספר בראש `kit/START-HERE.md`.
ערכה בגרסה אחת לא נפתחת מעל ערכה בגרסה אחרת, והפקודה אומרת מה לעשות.
כשפותחים שוב את אותה גרסה, הקבצים של הערכה חוזרים למצב המקורי, ושורה נוספת מפרטת קבצים בתיקייה
שלא שייכים לערכה. הפקודה לא מוחקת אותם.

## מה חשוב לדעת

- **המסך** הוא העתק של `site_health.html` שבשורש המאגר. מבנה הנתונים שהוא קורא נשאר זהה.
- **מה שמודד את האתר של דיוואני** יושב בסופאבייס ולא במאגר הזה. לכן החלק המודד בערכה
  (`reference/`) נכתב מחדש לפי מה שהמסך מציג ומסביר, ונבדק כאן. הוא לא העתק של מה שרץ בדיוואני.
- **קודקס לא מחזיק אף סיסמה או מפתח של האתר החדש.** בעל האתר פותח את החשבונות ומקליד את
  הסודות בעצמו, לפי ההודעות המוכנות שב-`OWNER-STEPS.md`.
- **מה לא נבדק כאן**, כי אין מכאן גישה: גוגל (מדידת המהירות), ntfy (ההודעות לטלפון), סופאבייס
  אמיתי, חנות אמיתית, וגם השמות של הכפתורים באתרים של הספקים. קודקס בודק את אלה בזמן ההתקנה,
  לפי הרשימה שב-`kit/spec/09-build-and-checks.md`.
- **מחירים לא כתובים בערכה.** קודקס מסביר לבעל האתר מה בדרך כלל בתשלום חודשי, ואת המחירים
  עצמם בודקים באתרים של הספקים.
