# ערכת "בריאות האתר"

כל מה שצריך כדי לבנות את מסך "בריאות האתר" לאתר אחר, בעזרת קודקס.

## מה נותנים לקודקס

את הקובץ **`SITE_HEALTH_KIT.md`**. זה קובץ אחד שמכיל הכול ופורס את עצמו לתיקייה.
ההודעה ששולחים לקודקס כתובה בראש הקובץ.

## מה יש כאן

| | |
|---|---|
| `SITE_HEALTH_KIT.md` | הקובץ למסירה. נבנה אוטומטית. לא עורכים אותו ביד |
| `kit/` | המקור שממנו הקובץ נבנה |
| `build_kit.py` | בונה את הקובץ מתוך `kit/` ובודק שהוא נפרס נכון |

בתוך `kit/`:

| | |
|---|---|
| `START-HERE.md` | הקובץ שקודקס קורא ראשון: כללי העבודה, השאלות לבעל האתר, סדר הבנייה |
| `spec/` | ההוראות המלאות: מה מודדים, מבנה הנתונים, המסך, המדידות, ההרשאות, הבדיקות |
| `site_health.html` | המסך עצמו. העתק של המסך בינשוף, בלי שום דבר של דיוואני |
| `mock_server.py` | שרת עם נתוני דמה, כדי לראות את המסך עובד |
| `check_screen.js` | בדיקת קבלה של המסך בדפדפן |
| `tools/check_template.py` | בודק שהמסך שנבנה הוא העתק של התבנית ולא כתיבה מחדש |
| `reference/` | דוגמה עובדת ובדוקה לכל מה שמאחורי המסך: מסד נתונים, שרת, מדידות, התראות |

## אחרי שינוי ב-`kit/`

```bash
python3 build_kit.py --check
```

## מה חשוב לדעת

- **המסך** הוא העתק של `site_health.html` שבשורש המאגר. מבנה הנתונים שהוא קורא נשאר זהה.
- **מה שמודד את האתר של דיוואני** יושב בסופאבייס ולא במאגר הזה. לכן החלק המודד בערכה
  (`reference/`) נכתב מחדש לפי מה שהמסך מציג ומסביר, ונבדק כאן. הוא לא העתק של מה שרץ בדיוואני.
- **מה לא נבדק כאן**, כי אין מכאן גישה: גוגל (מדידת המהירות), ntfy (ההתראות לטלפון), סופאבייס
  אמיתי, וחנות אמיתית. קודקס בודק את אלה בזמן ההתקנה, לפי רשימה שכתובה בהוראות.
